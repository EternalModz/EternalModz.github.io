Glitch Art

In this assignment, we were asked to use different methods to 'glitch' an image. I used popular wallpapers from Apple's macOS system as my base images. For three of these images, I used basic text editing to delete and modify sections, which produced several linear defects. For the macOS Ventura image, I used Audacity to apply a reverb audio effect over a RAW image format. I converted it back to an image file where the visualization of the effect can be seen.
